MOHAMMAD SIDDIQUI PORTFOLIO — GODADDY DEPLOYMENT

This website is fully static, so it works on standard GoDaddy Linux/cPanel hosting without Node.js, PHP, or a build step.

UPLOAD STEPS
1. Log in to GoDaddy and open your hosting dashboard.
2. Open File Manager / cPanel File Manager.
3. Open the domain's web root. This is usually public_html (or the folder assigned to your addon domain).
4. Upload EVERYTHING inside this portfolio folder to that web root.
5. Make sure index.html is directly inside the web root — not inside another nested folder.
6. Visit your domain and hard refresh the page.

FILES THAT MUST STAY TOGETHER
- index.html
- assets/css/styles.css
- assets/js/script.js
- assets/images/*
- assets/docs/Mohammad_Siddiqui_CV.pdf
- robots.txt

NO EXTERNAL IMAGE LICENSING
All illustrations in assets/images were created specifically for this portfolio as original SVG artwork. The site does not rely on stock-photo licensing.
