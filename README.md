# Mohammad Siddiqui — portfolio

Personal portfolio published at https://smat00.github.io/.

This is a static HTML/CSS/JavaScript website. No Node.js server, PHP, database or build step is required.

## Update the website

- Edit `index.html` for the profile, work list, background and contact details.
- Edit `projects/*.html` for individual project notes.
- Edit `assets/style.css` for the appearance.
- Replace `assets/Mohammad-Siddiqui-CV.pdf` to update the downloadable CV.
- Keep `.nojekyll` at the repository root so GitHub Pages publishes the files directly.

GitHub Pages publishes from the configured branch and folder. The website is intended for the root address `smat00.github.io`.

The email link opens the visitor's email app. No enquiries are stored and no automatic messages are sent.
