MSc project

Smoking status detection

Evaluating four classification models with feature selection and tuning.

Python · scikit-learn

View on GitHub Ask me about it

The question

How do different classification approaches compare when predicting smoking status from a dataset?

What I worked on

  • Built and benchmarked Random Forest, SVM, Decision Tree and Neural Network models.
  • Used Python, scikit-learn, Pandas and NumPy for the modelling workflow.
  • Applied feature selection and hyperparameter tuning, evaluating accuracy, precision, recall and F1-score.

The result

A structured comparison of four model families, using multiple evaluation measures to understand model behaviour.

This is an academic classification project, not a clinical diagnostic tool. No unverified accuracy score is presented.
